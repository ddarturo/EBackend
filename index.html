Arquitectura del Software

Este repositorio aloja la Capa 1 (Datos) y la Capa 2 (Aplicación/Backend) con el patrón arquitectónico MVC y patrones de diseño orientados a escalabilidad:

N-Capas & MVC

Separación estricta de rutas, controladores, middlewares y modelos.

Prisma ORM & Singleton

Gestión de una única instancia de conexión optimizada hacia PostgreSQL.

Repository Pattern

Abstracción de operaciones de datos con paginación, filtros y transacciones.

Factory Pattern

Factoría encargada de instanciar e inyectar dependencias entre capas.

Endpoints RESTful (API v1)

Base URL local: http://localhost:5050/api/v1

GET /api/v1/health
Comprobación de salud del servidor y estado activo
GET /api/v1/productos?page=1&limit=12&search=taladro
Listado paginado con búsqueda y metadatos
GET /api/v1/productos/:id
Búsqueda de producto específico por ID numérico
POST /api/v1/productos
Creación de nuevo producto con validación y sanitización
PUT /api/v1/productos/:id
Reemplazo total del recurso de producto
PATCH /api/v1/productos/:id
Actualización parcial (precio, stock o datos)
DELETE /api/v1/productos/:id
Eliminación física del producto con código 204

Puesta en Marcha Local

# 1. Clonar el repositorio
git clone https://github.com/ddarturo/EBackend.git
cd EBackend/capa2_backend

# 2. Instalar dependencias
npm install

# 3. Generar el cliente de Prisma ORM
npx prisma generate

# 4. Iniciar servidor Express en el puerto 5050
npm start
